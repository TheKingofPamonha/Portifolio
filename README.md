# Meu Portfólio Pessoal :rocket: (Em Construção)

Este repositório guarda o código-fonte do meu novo portfólio pessoal. Decidi reconstruir minha presença digital do zero, aplicando os fundamentos puros da web para consolidar meus conhecimentos em Front-end.

## :dart: Objetivo do Projeto
Criar um portfólio prático para demonstrar meus conhecimentos e evolução no desenvolvimento Front-end (HTML, CSS e JavaScript), construindo interfaces modernas, responsivas e focadas na experiência do usuário.

## 🛠️ Tecnologias Utilizadas
* **HTML5:** Estrutura semântica e boas práticas.
* **CSS3:** Variáveis globais, Flexbox para alinhamento e efeitos visuais de UI (Neon Hover, Box-shadow).
* **JavaScript:** Manipulação do DOM, scroll suave na navegação, lógica para o slider customizado de projetos e programação defensiva na interface do formulário.
